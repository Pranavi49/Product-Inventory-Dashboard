# JavaScript Internship Assessment & Mini Project

## Interactive Product Inventory & Analytics Dashboard

A JavaScript-based internship assessment project demonstrating fundamental programming concepts through six practical assignments and a product inventory management and analytics application.

## About the Project

The Interactive Product Inventory & Analytics Dashboard is a JavaScript application developed to manage product information, categorize products based on price, calculate inventory value, filter affordable products, and generate formatted inventory reports.

This project applies the core JavaScript concepts covered during the internship, including variables, data types, operators, conditional statements, loops, functions, arrays, objects, and array methods.

## Objectives

- Practice fundamental JavaScript programming concepts.
- Implement input handling and validation.
- Store and manage product information using arrays and objects.
- Categorize products using conditional statements.
- Calculate the total inventory value.
- Filter products based on their prices.
- Generate formatted product reports using array methods.
- Organize and maintain source code using Git and GitHub.

## JavaScript Assignments

### Assignment 1: Variables, Data Types, and Console Operations
Demonstrates variable declarations using `var`, `let`, and `const`, identifies data types using `typeof`, and displays information using `console.log()`.

### Assignment 2: Operators, Expressions, and Input Handling
Demonstrates user input, numeric type conversion, arithmetic operations, and bill calculation with a tip percentage.

### Assignment 3: Conditional Logic Implementation
Uses `if-else` statements, `switch`, and the ternary operator to evaluate scores, determine grades, and display pass/fail status.

### Assignment 4: Loop Control Structures
Demonstrates `for`, `while`, and `do-while` loops, together with `break` and `continue` statements.

### Assignment 5: Function Architecture and Scope
Implements regular functions, arrow functions, parameters, default values, return statements, and block-scope concepts.

### Assignment 6: Arrays, Objects, and Core Methods
Uses arrays of product objects and demonstrates `forEach()`, `filter()`, and `map()` to display, select, and transform product data.

## Mini Project Features

The Product Inventory & Analytics Dashboard integrates JavaScript concepts into a practical inventory application.

- **Product Management:** Stores product names and prices as objects in an array.
- **User Input:** Accepts product information, where supported by the implementation.
- **Input Validation:** Checks product information before processing.
- **Product Categorization:** Classifies products into Budget, Standard, and Premium categories according to the implemented price conditions.
- **Inventory Analytics:** Calculates the combined value of products.
- **Affordable Product Filtering:** Identifies products priced below $200.
- **Inventory Display:** Uses `forEach()` to display product details.
- **Formatted Reports:** Uses `map()` to generate readable product summaries.
- **Reusable Functions:** Organizes calculations and processing into functions.

## How to Run the Project

### Prerequisites

Install [Node.js](https://nodejs.org/) and [Visual Studio Code](https://code.visualstudio.com/) if they are not already installed.

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the actual URL of this repository.

### Step 2: Open the Project

Open the downloaded project folder in Visual Studio Code.

### Step 3: Run an Assignment

Open the terminal in VS Code and execute the required JavaScript file.

For example:

```bash
node Assignment_1.js
```

To run another assignment, replace the filename with the appropriate assignment file.

### Step 4: Run the Mini Project

Navigate to the folder containing the mini project's main JavaScript file.

For a Node.js-based application, execute:

```bash
node script.js
```

If the project uses a different entry-point filename, replace `script.js` with the actual filename.

If the dashboard is browser-based, open its `index.html` file in a browser instead.
